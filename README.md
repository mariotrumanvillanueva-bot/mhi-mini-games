# MHI Mini Games

GitHub Pages site for the general just-for-fun MHI Mini Games.

## Files included
- index.html
- style.css
- fun.js

## Important
This version does not need the Google Apps Script backend.
It saves fun scores locally in the browser.

Kahoot is included, but admin must open it using:

MHI-ADMIN-FRIDAY-2026

## Suggested GitHub repository name
mhi-mini-games

## GitHub Pages URL
After setup, your site will look like:

https://YOURUSERNAME.github.io/mhi-mini-games/
